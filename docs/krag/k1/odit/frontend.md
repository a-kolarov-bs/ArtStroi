# Фронтенд одит, АРТСТРОЙ (24.11.2026, само четене)

## Какво е проверено и как

| Страница | Desktop 1440 | Mobile 390 | Код / HTML |
|---|---|---|---|
| `/` | снимки по цялата страница | снимки по цялата страница | да |
| `/uslugi` | снимки по цялата страница | снимки по цялата страница | да |
| `/proekti` | снимки (горе, решетка, край) + филтър, търсене, `?cat=` | снимки (горе, решетка, край) | да |
| `/proekti/baza-za-otdih-ezerata-smolyan` (с локални снимки и „протокол“) | снимки | снимки | да |
| `/proekti/rekonstruktsiya-sektor-a-stadion-georgi-asparuhov` (legacy снимки) | снимки | снимки | да |
| `/za-nas` | снимки по цялата страница | снимки по цялата страница | да |
| `/kontakti` | снимки + форма (без пращане) | снимки + мобилно меню | да |
| 404 (`/nyama`) | само HTML (curl) | само HTML | да |

**Метод.** Headless (`pw.mjs`) пада при `start`, затова е ползван Chrome на потребителя (собствен таб, вече е затворен). Прозорецът не се смалява: `resize_window` не работи, `innerWidth` остава 1920. Затова страниците са заредени в два iframe-а на същия origin, широки **1440×900** и **390×844**, един до друг. Медийните заявки се смятат по ширината на iframe-а, така че mobile оформлението е **видяно на екран**, но без touch и без мобилен UA. Мерено е с JS вътре в iframe-а: височини и padding на секциите, шрифтове под 12px, преливане вдясно, CLS (layout-shift), заредени ресурси и състояние на Reveal. SEO, заглавия, alt и линкове са взети от HTML-а през curl и парсер.

**Не е проверено:** реално устройство или touch, реален Lighthouse, `prefers-reduced-motion` в браузъра (проверено е само по кода), production build (`npm run build` пише в `dist/` и не е пускан), клавиатурна навигация с Tab на екран, видеото в hero-то (по задание).

## Кое е добро и да се пази

- **Ритъм на тъмни и светли секции** и топлата кремава палитра с `#BA2D20`: изглежда скъпо и е свое, не шаблон.
- **Лентата с проекти горе на `/proekti`** (reel) и hover на снимките: силно първо впечатление и реални обекти.
- **Филтър, търсене и `?cat=` на `/proekti`** работят (проверено: `?cat=Инфраструктура` активира бутона и показва 6). Има празно състояние „Не намираме обект…“ и пагинация.
- **Детайлът на проект**: лента „Архив № 001/055 · категория · град“, карта с „Отваряне в Карти“, „Още проекти“, Breadcrumb JSON-LD и canonical на всяка страница.
- **Формата за контакт**: `<label for>` за всяко поле, `autocomplete` (given-name, family-name, tel, email), `aria-invalid`, `aria-live`, `novalidate` + собствена проверка.
- **Мобилното меню**: `aria-expanded`, `aria-controls`, `inert` при затворено, затваряне с Escape.
- **CLS ≈ 0** на всички мерени страници (0.000–0.006). Няма хоризонтално преливане на 390px.
- **Глобален `prefers-reduced-motion`** в `global.css:320` плюс отделни fallback-ове в 15 компонента. `:focus-visible` има брандов outline.
- **Типографията с Poiret One в големите размери** (hero, „Сграда на годината“, заглавията на секциите) работи много добре. Проблемът е само под ~16px (В7).
- **Футърът**: ясни телефони по роли с `tel:` и работно време.
